## 開き方

1. Shotcut（無料, https://shotcut.org ）をインストールします。
2. **フォルダごと**コピーしてから `IMG_0299_edit.mlt` を開きます。素材は相対パスで参照しているので、フォルダの構成は変えないでください。
3. 字幕とタイトルのフォントは **Noto Sans CJK JP**（Black）です。フォントが入っていない場合は別のフォントで表示されます。フォントは https://fonts.google.com/noto/specimen/Noto+Sans+JP から入手できます（「Noto Sans JP」を選び直してください）。

## 書き出しをやり直す場合

- Shotcut: 「書き出し」で「H.264 High Profile」を選びます。解像度は 1080×1920 / 30fps です。
- コマンド: `melt IMG_0299_edit.mlt -consumer avformat:export/IMG_0299_final.mp4 vcodec=libx264 crf=18 acodec=aac ab=192k`（Linuxでディスプレイがない環境では `xvfb-run -a` を前に付けます）
- `tools/build_project.py` は最初の編集を再現するためのスクリプトです。実行すると `.mlt` が上書きされ、Shotcut での変更は消えるので注意してください。
